## Native release trial

`benchmarks/scripts/s6-trial.ps1`, separately with `winit-software` and `winit-femtovg`.
Each run starts a real TLS/WSS server, PostgreSQL and seven native client processes
across three scenarios, all on an isolated invisible Windows desktop. No desktop
switch, input injection, focus acquisition, screen capture or real audio devices.
The client's real media pipeline/SFU uses simulated audio.

Counts prove media flow in these trials; they are not latency, quality, capacity or
startup benchmarks. Own-renderer snapshots were visually inspected: creator group
controls, member-only group view, direct history and retained draft. OpenGL member
view also inspected. Snapshots contain only the app, never the user's desktop.

An earlier trial found an actual draft race: an older Open snapshot could overwrite
the UI-local draft before the saved draft was published. Fixed by publishing a new
Service conversation snapshot after SaveDraft, with regression coverage and repeated
native passes. Another direct-trial attempt used profiles longer than the existing
32-character CLI limit; the harness now uses short unique profiles. These failed
attempts are not counted as passing evidence.

ignored local/build directories. This report contains only synthetic labels/counts.

remain owner-assisted and separate (ADR 0012). No remote push or CI run claimed.
